# Quantum Monolith

An interactive 3D particle visualization built with Three.js and MediaPipe Hand Tracking.

## Live Demo

* https://shubhanshu1978.netlify.app/

## Features

* Real-time 3D particle rendering
* Hand gesture recognition using MediaPipe
* 8 morphing particle structures
* Mouse and gesture-based zoom/rotation
* Smooth particle physics animations
* Dynamic shape transitions and particle implosion effects
* Fully browser-based experience with webcam interaction

## Controls

* **Mouse Drag** → Rotate
* **Mouse Wheel** → Zoom
* **Two Hands** → Zoom In/Out
* **Pinch Gesture** → Switch Shapes
* **Fist Gesture** → Implode Particles

## Tech Stack

* Three.js
* MediaPipe Vision Tasks
* JavaScript
* WebGL

## Run

* Clone the repository
* Open `index.html` in a modern browser
* Allow webcam access when prompted
* Start interacting with the particle system using gestures

## Why I Built This

* To explore computer vision in the browser
* To experiment with real-time particle systems and physics
* To combine hand tracking with interactive 3D graphics
* To learn more about Three.js and WebGL
